## 🚀 Projects Completed

### 1. Hangman Word Guessing Game

A terminal-based Hangman game where the player guesses a hidden word one letter at a time.

**Features:**
- Random word selection
- Hidden word display
- Maximum of 6 incorrect guesses
- ASCII Hangman stages
- Previously guessed letter tracking
- Duplicate guesses do not reduce attempts
- Input validation
- Win and loss handling
- Replay option

**Folder:**

```text
Task1_Hangman/
├── hangman.py
└── words.txt
```

**Run:**

```bash
cd Task1_Hangman
python hangman.py
```

### 3. Automated File Organizer & Cleanup Utility

A command-line utility that automatically organizes files into folders according to their file extensions.

**Features:**
- Preview organization before moving files
- Organize files by category
- Supports images, documents, spreadsheets, presentations, videos, audio, archives, and code
- Handles unknown file types using an `Others` category
- Prevents filename conflicts
- Confirmation before moving files
- Safe file movement using Python's file-handling modules

**Folder:**

```text

└── file_organizer.py
```

**Run:**

```bash
cd Task3_File_Organizer
python file_organizer.py
```
